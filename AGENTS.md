# Правила проекта TorrentCreator

## Версионирование и теги релизов
- Для каждой новой версии проекта тег создается в формате `vX.Y.Z` (аннотированный тег `git tag -a`).
- В описании тега, описании релиза на GitHub и в файле `CHANGELOG.md` **всегда на русском языке** подробно указывается, что было исправлено и добавлено по отношению к предыдущей версии:
  - **Добавлено**: новый функционал, кнопки, интеграции.
  - **Исправлено**: баги, исправления поведения, селекторы трекеров, логика автоопределения.
  - **Улучшено/Сборка**: изменения в пайплайнах, PyApp, GitHub Actions, оптимизация интерфейса.
