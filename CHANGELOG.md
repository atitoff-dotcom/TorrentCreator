# История изменений (Changelog)

## [v1.0.2] - 2026-10-03

### 🚀 Добавлено
- **Индикатор прогресса загрузки скриншотов**:
  - В глобальный оверлей добавлен стилизованный градиентный прогресс-бар и процент выполнения (`0%` &rarr; `100%`).
  - При отправке отобранных скриншотов на Fastpic статус и прогресс-бар обновляются в реальном времени для каждого кадра (`Загрузка кадра 2 из 4 (50%)`).
  - В `AppAPI` добавлен метод поштучной отправки `upload_single_screenshot`.

## [v1.0.1] - 2026-10-03

### 🛠️ Исправлено
- **Всплывающие консольные окна при открытии медиафайла**:
  - Для всех фоновых вызовов `ffmpeg` и `ffprobe` при анализе медиафайла, извлечении субтитров и нарезке скриншотов добавлен флаг создания процесса `CREATE_NO_WINDOW` (`0x08000000`) и режим сокрытия окон `SW_HIDE`. Теперь при нарезке 12+ скриншотов консольные окна больше не мелькают на экране.
- **Окно инструментов веб-разработчика (DevTools)**:
  - Отключен отладочный режим `debug=False` в `webview.start()`. Дополнительное окно инспектора/отладки Chromium DevTools больше не открывается при старте приложения.

## [v1.0.0] - 2026-10-03

Первый стабильный релиз TorrentCreator — инструмента для оформления и создания раздач на трекерах (Кинозал.ТВ, RuTracker.org).

### 🚀 Добавлено
- **Современный GUI интерфейс**:
  - Построен на базе WebView2 с кастомным интерфейсом в темном и светлом стиле, переключением тем и интерактивными вкладками.
  - Интеграция с локальным API через `pywebview`.
- **Поиск и оформление метаданных**:
  - Интеграция с Кинопоиск API и TMDb API.
  - Автоматическое заполнение постеров, года выпуска, страны, режиссеров, актёров, оригинального названия, аннотации и оценок (КП / IMDb).
- **Медиа-анализ и скриншоты**:
  - Полный разбор медиафайлов через MediaInfo: видеокодеки, разрешение, битрейт, профили, форматы аудио (каналы, язык, частота).
  - Создание скриншотов с заданным шагом и количеством.
  - Пакетная загрузка скриншотов на Fastpic.org с выбором размера превью и качества сжатия.
- **Создание .torrent файлов**:
  - Автоматический расчет оптимального размера куска (piece size).
  - Вшивание анонсеров трекеров и установка флага приватности.
- **Автоматический инфо-файл MediaInfo**:
  - Автоматическая анонимная выгрузка полного дампа MediaInfo на paste-сервис (Rentry.co) при генерации раздачи.
  - Формирование тега `[linkm=Инфо-файл]URL[/linkm]` для Кинозала и соответствующего блока для RuTracker.
  - Кнопка ручной отправки и поле редактирования ссылки в интерфейсе.
- **Глобальный спиннер загрузки и блокировка интерфейса**:
  - Стеклянный (glassmorphic) анимированный оверлей (`#globalLoader`), блокирующий клики во время длительных фоновых задач (анализ медиа, скриншоты, заливка на хостинг, поиск, автозаполнение браузера).
- **Автозаполнение веб-форм через браузер**:
  - Интеграция с браузером Chrome через `nodriver` для автоматического открытия страниц создания тем на Кинозале и Рутрекере с предзаполнением всех полей, категорий и описаний.

### 🛠️ Исправлено
- **Логика определения отечественных фильмов**:
  - Исправлена ошибочная классификация зарубежных фильмов без оригинального названия как отечественных.
  - Отечественными признаются строго фильмы с `original_language == "ru"` либо производства РФ/СССР.
  - Для зарубежных фильмов с русской аудиодорожкой дорожка больше не помечается как «Оригинал», а корректно выставляется тип перевода (`ДБ`, `ПМ` и т.д.).
- **Синхронизация полей релиза**:
  - Автоматическое обновление аудиотреков и подкатегорий трекеров при повторном получении метаданных из поиска.

### 📦 Сборка и дистрибуция
- **Rust-упаковщик PyApp**:
  - Создание полностью автономного исполняемого файла `TorrentCreator.exe` (~23.8 МБ) без черного окна консоли (`PYAPP_IS_GUI=1`).
  - Встроенный рантайм Python 3.12 и менеджер пакетов UV для молниеносной инициализации окружения.
  - Локальный скрипт сборки `build_pyapp.ps1`.
- **GitHub Actions CI/CD**:
  - Автоматическая кроссплатформенная матричная сборка для Windows, Linux и macOS по тегу `v*`.
  - Автоматическое создание релизов в GitHub Releases с прикреплением готовых бинарников.
- **Безопасность**:
  - Файл конфигурации `config.json` с приватными ключами исключен из Git-репозитория (`.gitignore`).
  - Автоопределение пути: приоритет локальной рабочей папки, резервное хранение в `~/.torrentcreator/config.json`.
