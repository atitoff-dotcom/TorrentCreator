# Техническое задание (ТЗ): TorrentCreator

## 1. Назначение и цель проекта
Разработка кроссплатформенного десктопного приложения с графическим веб-интерфейсом для автоматизации создания и оформления раздач на торрент-трекерах **RuTracker.org** и **Kinozal.tv** из локальных медиафайлов (`.mkv`) и папок с сериалами.

Режим работы — **полуавтоматический**: программа извлекает технические данные, запрашивает метаданные из внешних баз, готовит и загружает скриншоты, формирует специфичное оформление под правила каждого трекера и предзаполняет форму на веб-странице в браузере пользователя для финального подтверждения. (Создание самого торрент-файла пользователь выполняет в привычном торрент-клиенте).

---

## 2. Стек технологий и архитектура
* **Ядро (Backend):** Python 3.14+
  * `pywebview` — отображение графического интерфейса (на Windows используется нативный Edge WebView2, легковесность без оверхеда Electron).
  * `pymediainfo` / `mediainfo` — извлечение полных метаданных видео/аудио/субтитров.
  * `ffmpeg` — нарезка скриншотов с анализом кадров.
  * `requests` / `urllib` — интеграция с API Кинопоиска, TMDb, IMDb и хостингами скриншотов.
* **Пользовательский интерфейс (Frontend):**
  * Чистый HTML5 + Modern CSS (CSS Custom Properties / токены тем) + Vanilla JavaScript (ES Modules).
  * Минимальный расход токенов контекста модели при сопровождении и разработке (отсутствие тяжелых UI-библиотек и этапов сборки).
  * **Две темы оформления:** Светлая (Light) и Темная (Dark) с сохранением выбора пользователя.
* **Сборка и дистрибуция:**
  * GitHub Actions Matrix CI/CD для автоматической сборки под Windows (.exe), Linux и macOS при выпуске релизов.

## 3. Пользовательский интерфейс и пошаговый процесс (User Flow)

### Вкладка 1. «Медиа и Метаданные»
1. **Выбор файла / папки:**
   * Кнопка «Выбрать видеофайл (.mkv)» — для одиночных фильмов/серий.
   * Кнопка «Выбрать папку (сериал)» — для папок с сезонами/сериями.
   * Определение названия фильма/сериала, года, сезона/эпизодов, характеристик рипа из названия.
2. **Двухколоночный интерфейс:**
   * **Левая колонка (Данные из файла / MediaInfo):**
     * Имя файла, размер, продолжительность.
     * Параметры видео: разрешение, кодек, соотношение сторон, частота кадров, битрейт.
     * Аудиодорожки: язык, кодек, число каналов, битрейт, внутренние названия дорожек.
     * Текстовые дорожки (субтитры): язык, формат, тип (полные, форсированные).
   * **Правая колонка (Данные из внешних баз):**
     * Источники: **Кинопоиск API**, **TMDb**, **IMDb**.
     * Поле ручной корректировки / вставки прямой ссылки на страницу фильма/сериала.
     * Галерея постеров с возможностью выбора постера высокого разрешения.
     * Названия (русское и оригинальное), год, страна, жанры, режиссеры, актерский состав, синопсис.

### Вкладка 2. «Скриншоты»
1. **Двухколоночный отбор кадров:**
   * **Слева (Нарезанные кадры):**
     * Автоматическая нарезка серии кадров (12–16 шт.) с пропуском титров и темных сцен. Для сериалов — кадры распределяются по разным сериям.
     * Кнопка быстрой донарезки кадров.
   * **Правая колонка (Отобранные в релиз):**
     * Перенос нужных кадров (обычно 4–6 шт.) в список публикации (Drag & Drop или клик).
     * Возможность удаления неудачных кадров и изменения их порядка.
2. **Хостинг изображений:**
   * Автоматическая загрузка отобранных скриншотов на фотохостинг, входящий в «белый список» трекеров (Fastpic, Postimages).
   * Формирование кликабельных превью (требование правил трекеров).

### Вкладка 3. «Параметры релиза и Публикация»
1. **Уточнение недостающих данных:**
   * Сопоставление аудиодорожек: указание типа перевода (*Дублированный, Профессиональный многоголосый, Авторский, Оригинал*) и студии (*LostFilm, Red Head Sound, HDRezka* и др.).
   * Для сериалов: сезон, статус (*Раздача завершена / Обновляется*).
   * Автоопределение подходящих категорий/подразделов трекеров.
2. **Формирование раздачи:**
   * Генерация строгого заголовка темы RuTracker и полей Kinozal.
   * Полный BB-код со спойлерами (MediaInfo, скриншоты-превью, описание).
3. **Полная автоматизация через nodriver (чистый Python + CDP, Persistent Profile):**
   * Кнопка «🌐 Открыть и заполнить Kinozal» или «🌐 Открыть и заполнить RuTracker».
   * Запускает установленный в системе Chrome с постоянным профилем (`~/.torrent_creator_browser_profile`).
   * **Чистый Python без Node.js**: использование `nodriver` позволило полностью избавиться от 93 МБ оверхеда Node.js/Playwright.
   * Нативная защита от детекта автоматизации и обход Cloudflare (разработка автора `undetected-chromedriver`).
   * Пользователь логинится на трекере всего один раз — браузер запоминает авторизацию и куки навсегда.
   * Все поля формы (заголовок, постер, год, режиссеры, актеры, видео, аудио, скриншоты, сюжет/BB-код) заполняются автоматически и подсвечиваются зеленым.
   * Не требует никаких сторонних расширений, переключателей «режима разработчика» или закладок.
   * Сырой блок предварительного просмотра BB-кода убран как избыточный при наличии прямой автоматической заливки в браузер.
4. **Планы на следующий этап (Ручное редактирование полей перед отправкой):**
   * Удобные поля предварительного просмотра и ручной корректировки каждого параметра (название, техданные, список актеров, сюжет) перед кликом на автозаполнение.

### Вкладка 4. «Настройки»
* Локальное хранение конфигурации (`config.json`):
  * Выбранная тема (светлая/темная).
  * API-ключи: Кинопоиск, TMDb.
  * Персональный Passkey для Kinozal.
  * Папка сохранения создаваемых `.torrent` файлов.
  * Параметры скриншотов (кол-во, ширина превью, хостинг).

## 4. Специфика трекеров и правила оформления

### RuTracker.org:
* **Заголовок темы:** Строгий шаблон `Название / Оригинальное (Режиссер) [Год, Жанр, Качество] [Озвучка] [Субтитры]`.
* **Тело релиза (BB-код):**
  * Постер с ограничением по ширине.
  * Текстовый блок описания и параметров.
  * Скриншоты строго в формате `[url=оригинал][img]превью[/img][/url]`.
  * `MediaInfo` обязательно внутри `[spoiler="MediaInfo"]...[/spoiler]`.
* **Торрент:** Чистый торрент без сторонних announce-URL.

### Kinozal.tv:
* **Модульная форма:**
  * Заполнение отдельных полей: русское/оригинальное название, год, страна, режиссер, актеры, жанр.
  * Строки технического качества: Видео (`1920x1080 at ...`), Аудио (перечень дорожек с битрейтом), Перевод (тип + студия).
  * Ссылки на скриншоты в соответствующие поля.
* **Торрент:** Announce-URL с персональным passkey пользователя.

## 6. Планы на развитие (Roadmap): Упрощение работы для пользователей (Zero-Configuration)
1. **Интерактивный ассистент получения API-ключей через браузерный движок (`nodriver`):**
   * **Kinopoisk Unofficial API:**
     * Открытие личного кабинета (`kinopoiskapiunofficial.tech/profile`) в изолированном профиле браузера.
     * Ожидание авторизации пользователя и автоматический захват UUID-токена со страницы профиля.
     * Валидация тестовым запросом и автоматическое сохранение в `config.json` без ручного копирования.
   * **TMDb API (The Movie Database):**
     * Навигация на страницу создания ключа разработчика (`/settings/api/new/developer`).
     * Автоматическое подтверждение лицензионного соглашения (Terms of Use).
     * **Автозаполнение сложной анкеты разработчика:**
       * *Application Name:* нейтральное название (например, `Home Video Cataloger`).
       * *Application URL:* ссылка-заглушка (`https://github.com`).
       * *Application Summary:* готовое безопасное описание домашней офлайн-медиатеки (без стоп-слов вроде *torrent*, *tracker*, *download*).
       * *Тип и контактные поля:* автоматическое заполнение обязательных полей формы нейтральными валидными данными.
     * Автоматический перехват сгенерированного **v3 API Key** со страницы настроек API.
     * Мгновенный тест ключа и запись в конфигурацию приложения с визуальным уведомлением в интерфейсе.
2. **Встроенный резервный/демо поиск «из коробки»:**
   * Проксирование или использование базового ключа по умолчанию для мгновенного поиска без обязательной первоначальной настройки.
